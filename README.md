Pixel-perfect static webpage built with Semantic HTML5, BEM CSS, 12-Column Grid &amp; Flexbox for DecodeLabs Project 1

#craft&Code Studio — Foundations of Visual Architecture

A pixel-perfect, highly responsive, and accessible multi-page static website built strictly in compliance with modern web standards and modular styling methodologies. Developed as part of the 
DecodeLabs Frontend Project 1: Foundations of Visual Architecture (assignment.)

---

##Key Features & Highlights

- **Multi-Page Architecture:** Includes `Home`, `Services`, and `Contact` pages with a seamless, interconnected navigation structure.
- **Strict Semantic Structure:** Developed entirely with standard HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`, `<address>`).
- **Strict Heading Hierarchy:** Guaranteed single `<h1>` per page with an unbroken structural sequence (`h1` → `h2` → `h3` → `h4`).
- **Scalable BEM CSS Engineering:** Built using the Block-Element-Modifier (BEM) naming convention (`.block__element--modifier`) without using IDs for styling, following strict DRY (Don't Repeat Yourself) principles.
- **Dual Layout Architecture:**
  - **CSS Grid:** Powers the macro layout (12-column grid system with 24px gutters, fixed 1200px max-width container, and 120px vertical padding).
  - **Flexbox:** Controls micro-level alignments (headers, nav menus, cards, and interactive forms).
- **Accessibility & Performance (A11Y & CLS):**
  - High contrast ratio (> 4.5:1) meeting WCAG standards.
  - Explicit image dimension attributes (`width` and `height`) to prevent Cumulative Layout Shift (CLS).
  - Descriptive `alt` tags and `aria-label` attributes for assistive technology compatibility.

---

##Tech Stack & Standards

- **Language:** HTML5, CSS3
- **Architecture:** BEM (Block Element Modifier), DRY CSS
- **Layout Engines:** CSS Grid & Flexbox
- **Design System:** Responsive, Minimalist, A11Y Compliant
